# Telegram MP3 Metadata Bot

Бот для изменения ID3-метаданных MP3 прямо через Telegram.

## Что умеет

- название
- исполнитель
- альбом
- год
- жанр
- номер трека
- номер диска
- встроенная обложка JPG/PNG
- очистка метаданных
- массовое изменение полей
- отправка готового MP3

## Запуск

Нужен Python 3.10+.

### 1. Создай бота

В Telegram открой @BotFather, выполни /newbot и получи токен.

### 2. Установи зависимости

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Потом:

```bash
pip install -r requirements.txt
```

### 3. Создай .env

Скопируй `.env.example` в `.env` и вставь токен:

BOT_TOKEN=твой_токен

### 4. Запусти

```bash
python bot.py
```

После запуска открой своего бота в Telegram и отправь /start.

## Важно

Эта версия хранит текущий MP3 во временной папке `storage/<user_id>` на сервере.
Если бот будет публичным, перед публикацией стоит добавить:
- авторизацию/админ-панель
- автоматическое удаление файлов через N минут
- ограничение размера и количества файлов
- очередь обработки
- rate limit
- Docker/deployment-конфигурацию
